# sameerchib.com — design tokens

Editorial monochrome layout. Implementation lives in [`styles.css`](styles.css) (`:root` tokens).

- **Background:** `#FFFFFF` / surface `#FAFAFA`
- **Ink:** `#0A0A0A` with soft `#5A5A56` and faint `#B4B4B0`
- **Display:** Syne (600–800)
- **Body:** Public Sans
- **Mono / labels:** JetBrains Mono, uppercase, wide letter-spacing

Bump the version comment in `styles.css` when you materially change tokens or section layout.
